## Cách kiểm tra chéo URL nghi ngờ ở Vùng Vàng (VirusTotal, URLScan, WHOIS)
Keywords: kiểm tra chéo virustotal urlscan whois domain age tuổi tên miền vùng vàng cross check
Khi PhishingGuard xếp một link vào **Vùng Vàng (Đáng ngờ)**, bạn có thể kiểm tra chéo an toàn mà không cần truy cập trực tiếp: 1) Dán URL vào **VirusTotal** (`virustotal.com`) để xem kết quả quét từ hơn 70 hãng bảo mật. 2) Dùng **URLScan.io** để xem ảnh chụp màn hình trang web từ máy chủ sandbox từ xa. 3) Kiểm tra **WHOIS / Domain Age**: tên miền ngân hàng/dịch vụ lớn thường tồn tại nhiều năm, trong khi tên miền lừa đảo thường mới đăng ký chỉ vài giờ đến vài ngày.

## An toàn trình duyệt, Extension độc hại và Thông báo rác (Notification Spam)
Keywords: extension độc hại tiện ích mở rộng notification spam thông báo rác cập nhật chrome browser security
1) Chỉ cài Chrome Extension từ **Chrome Web Store** có nhà phát triển rõ ràng và đọc kỹ quyền truy cập (Permissions). 2) Nhiều trang web lừa đảo bật hộp thoại "Bấm Allow để chứng minh không phải robot" nhằm gửi thông báo rác giả mạo cảnh báo virus Windows — nếu lỡ bấm, vào `chrome://settings/content/notifications` để xóa trang đó khỏi danh sách **Allowed**. 3) Luôn bật cập nhật tự động cho Chrome/Edge để vá lỗ hổng bảo mật zero-day.

## Rủi ro khi dùng Wi-Fi công cộng và Trạm phát giả (Evil Twin)
Keywords: wifi wi-fi hotspot evil twin captive portal vpn cafe sân bay public wifi
Kẻ tấn công có thể dựng điểm phát Wi-Fi miễn phí giả mạo (Evil Twin, vd: "Free_Airport_WiFi") kèm trang đăng nhập Captive Portal giả để dụ nhập mật khẩu hoặc nghe lén lưu lượng chưa mã hóa. Khi giao dịch ngân hàng hoặc đăng nhập tài khoản quan trọng bên ngoài, hãy ưu tiên dùng mạng **4G/5G cá nhân** hoặc bật **VPN uy tín**, và tắt tính năng tự động kết nối Wi-Fi mở.
